# Web Scraping Quotes

## Deskripsi
Project ini dibuat untuk melakukan web scraping menggunakan Python
pada website Quotes to Scrape.

## Website yang Digunakan
https://quotes.toscrape.com/

## Tools yang Digunakan
- Python
- Visual Studio Code
- Requests
- BeautifulSoup
- Pandas
- OpenPyXL

## Data yang Diambil
- Quote
- Author
- Tags

## Output
Hasil scraping disimpan dalam bentuk:
- CSV
- Excel
